# 山海灵境

竖屏 2D 国风策略小游戏：御使墨灵，连接古树，争夺灵脉。

**[在线试玩](https://liyunfei476-blip.github.io/shanhai-lingjing/)** · 建议手机竖屏打开。

## 玩法

- 从己方古树直接拖向目标出灵；空白处拖出圆形选区，向外扩大、往回缩小，松手后圆圈立即消失，墨灵保留高亮；从所选区域或高亮墨灵处拖向目标出兵。圈到多少墨灵就派多少，无需圈住树心。
- 墨灵环绕古树巡游，沿灵脉行军；占领、进阶、攻破生机与兵力上限构成基础对局。
- 三棵相连的己方古树触发灵脉共鸣，提高内部行军速度和脱战恢复；切断连接即可破阵。
- 七种灵符、三种独立 AI 行为、12 / 18 / 24 处古树地图。

## 本地运行

使用 Node.js 22，无需安装依赖。

```sh
npm start
```

打开 http://localhost:4187/ 。

```sh
npm test             # 规则与圆形选区测试
npm run simulate    # AI 完整对局模拟
npm run build       # 生成离线单文件
npm run build:pages # 生成 _site 静态站点
```

## 部署

GitHub 仓库的 Settings → Pages → Source 选择 GitHub Actions。
推送到 main 后，工作流运行测试并发布 `_site/`。所有运行资源使用相对路径，支持仓库子路径部署。
